# Agenda em Python (Console)
Uma aplicação simples de agenda desenvolvida como projeto acadêmico para gerenciar contatos e compromissos diretamente pelo terminal.
Pelo menos era esse o seu objetivo inicial, mas eu quiz fazer algo mais voltado para jogos, como listar jogos ainda não jogados e, confomrme
fosse terminando, a lista pode ser atualizada, visto que as adições são colocadas em um arquivo JSON.

#  Tecnologias e Conceitos Utilizados
- **Linguagem:** Python 3
- **Conceitos aplicados:** Estruturas de repetição (`while`, `for`), condicionais (`if/elif/else`), listas/dicionários e manipulação de funções.

#  Funcionalidades
O programa exibe um menu interativo no terminal com as seguintes opções:
- **1.** Adicionar novo contato/compromisso.
- **2.** Listar todos os itens cadastrados.
- **3.** Excluir um registro.
- **4.** Sair do programa.
